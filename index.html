Remote Sensing and Machine Learning

Grapevine Cultivar Discrimination Using Proximal Hyperspectral Data and Machine Learning

Focus: This report tested whether proximal hyperspectral ASD leaf spectra and machine learning could discriminate six raisin grapevine cultivars. It used December 2023 and January 2024 datasets and treated temporal transferability as an important part of the evaluation.

Technical work: Atmospheric absorption windows were removed before modelling, leaving 1,874 retained wavebands. The workflow compared Random Forest and SVM models with feature selection and transformation methods including Boruta, RFE, PLS-VIP, PCA and spectral binning.

Result and interpretation: The baseline linear SVM was the strongest December model. Model 2 achieved OA = 0.8923 and MCC = 0.8709. SVM + RFE also performed strongly while using only 100 wavebands. Temporal transferability to January was poor, showing that the spectral signatures were not stable across time.

Development shown: This project shows Python, hyperspectral data processing, machine learning, model comparison, feature selection, accuracy assessment and critical interpretation.

Data Pipeline and Database Loading

Food Lover's Market Store Location Scraper

Focus: This project involved building a reusable data process for keeping a food market retailer's store locations up to date. The workflow collected Food Lover's Market store locations from a public website and prepared the result as a clean dataset for SQL Server.

Technical work: The required fields included a branch or stable identifier, store name, address line, city or suburb, province, postal code, latitude and longitude. The deliverables included a stores.csv output, a SQL Server create table script for dbo.Stores, scraping code and Python code to load the CSV into SQL Server.

Development shown: The project is relevant to Geoinformatics because it deals with spatially referenced store data, coordinates, data quality, structured attributes and database loading. It shows Python, web scraping, CSV preparation, Excel checking and repeatable data handling.
